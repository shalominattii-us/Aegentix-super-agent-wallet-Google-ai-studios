OmniCyberDex for Xaman

The app key for the OmniCyberDex XRPL integration is a server environment variable. This page does not ask for it and does not store it.

Use XAMAN_API_KEY for the OmniCyberDex XRPL app key. XAMAN_API_SECRET can stay empty: the simulation features below do not use it. Restart the Node process after editing .env. A XUMM_API_KEY entry is a different name and does not satisfy this check.

Presence is reported by GET /api/xaman/readiness. The response contains booleans only.
