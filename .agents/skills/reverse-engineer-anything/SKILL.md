# Reverse Engineer Anything (REA)

Use this skill when analyzing, auditing, reverse-engineering, or reconstructing applications, desktop terminals, binary layouts, or software architectures.

## Core Capabilities
1. **Application Architecture Analysis**:
   - Inspect layout, component composition, state management, and lifecycle.
   - Deconstruct multi-panel terminal cockpits, data grids, and high-density telemetry decks.
   - Trace network endpoints, WebSockets, REST APIs, and binary RPC channels.
2. **Binary & Asset Extraction**:
   - Unpack native libraries, resource bundles, themes, and configuration tables.
   - Extract UI styles, tokens, fonts, and chart renderers.
3. **Behavioral Reconstruction**:
   - Recreate high-performance application modules in clean, modern frameworks (React / TypeScript / C++ / WebAssembly).
   - Re-implement real-time market data pipelines, order books, and financial charts without external dependencies.
